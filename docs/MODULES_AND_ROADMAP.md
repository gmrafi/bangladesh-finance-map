## Delivery phases

### Phase 0 — Research and validation

Archive original research; audit data sources, redistribution rights, Bangladesh map coverage, regulatory constraints and 15–20 target-user interviews. Define data confidence and source provenance standards.

### Phase 1 — Shared platform

Next.js TypeScript app, premium responsive design system, navigation, mapping abstraction, source/methodology pages, analytics with privacy controls, quality gates and deployment pipeline.

### Phase 2 — বাসাIQ MVP

Dhaka neighborhood dataset, interactive map, budget/workplace preferences, housing and commute cost assumptions, compare view, shareable scenario, and honest uncertainty labels.

### Phase 3 — Acquisition satellites

Small TaxLens Job Offer Calculator and Commute Cost Calculator integrated into the same product, not standalone clones. Validate conversion into flagship use.

### Phase 4 — Broader module rollout

CardMap BD, Property Due-Diligence, Salary Reality, Home-Loan, NRB Money Route, Entrepreneur Lab and Safe-Yield as licensing, reliable data, product demand and compliance allow.

## Readiness gates for every module

1. Confirm a distinct user decision that the module improves.
2. Identify legal, reliable and adequately fresh data.
3. Define input/output schema and formula or decision methodology.
4. Build an interactive prototype with transparent caveats.
5. Test mobile usability, performance, accuracy and accessibility.
6. Add sharing only where privacy-safe and useful.
7. Launch with visible source, timestamp and corrections process.

## Roadmap interpretation

The original report includes a 30/90-day launch plan with illustrative dates. Preserve those dates **in the original report**; this delivery tracker uses phases rather than pretending that those deadlines are committed or that work has already happened.
